# ClipJot API v1

> REST API for ClipJot bookmark management

## Overview

The ClipJot API provides programmatic access to your bookmarks. All endpoints:
- Use **POST** method
- Accept and return **JSON**
- Require `Content-Type: application/json` header

**Base URL:** `https://your-domain.com/api/v1`

## Authentication

Most endpoints require authentication via Bearer token:

```
Authorization: Bearer YOUR_TOKEN
```

### Token Types

- **Session tokens** - Created during OAuth login, used by web UI and mobile apps
- **API tokens** - Created in Settings > API Tokens, for scripts and integrations

### Token Scopes

- `read` - Can read bookmarks and tags
- `write` - Can read, create, update, and delete bookmarks and tags

## Endpoints

### Authentication

#### POST /api/v1/auth/invite

Exchange an invite code for a session token. **Public endpoint** (no auth required).

**Request:**
```json
{
  "code": "ABC12345"
}
```

**Response:**
```json
{
  "token": "session-token-here",
  "user": {"id": 1, "email": "user@example.com"}
}
```

#### POST /api/v1/logout

Revoke the current session. Scope: `read`

**Request:** `{}`

**Response:**
```json
{
  "logged_out": true,
  "message": "Session revoked"
}
```

### Bookmarks

#### POST /api/v1/bookmarks/add

Create a new bookmark. Scope: `write`

**Request:**
```json
{
  "url": "https://example.com/article",
  "title": "Interesting Article",
  "comment": "Read this later",
  "tags": ["reading", "tech"]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| url | string | Yes | The URL to bookmark |
| title | string | No | Display title |
| comment | string | No | Personal note |
| tags | array | No | List of tag names (created if they don't exist) |

**Response:**
```json
{
  "id": 123,
  "url": "https://example.com/article",
  "title": "Interesting Article",
  "comment": "Read this later",
  "tags": [{"id": 1, "name": "reading"}, {"id": 2, "name": "tech"}],
  "created_at": "2025-01-15T10:30:00Z",
  "updated_at": "2025-01-15T10:30:00Z"
}
```

#### POST /api/v1/bookmarks/edit

Update an existing bookmark. Scope: `write`

**Request:**
```json
{
  "id": 123,
  "title": "Updated Title",
  "comment": "New notes",
  "tags": ["important", "work"]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| id | integer | Yes | Bookmark ID to update |
| title | string | No | New title |
| comment | string | No | New comment |
| tags | array | No | New tag list (replaces existing) |

#### POST /api/v1/bookmarks/delete

Delete a bookmark. Scope: `write`

**Request:**
```json
{
  "id": 123
}
```

**Response:**
```json
{
  "deleted": true
}
```

#### POST /api/v1/bookmarks/search

Search bookmarks by query. Scope: `read`

**Request:**
```json
{
  "query": "python tutorial",
  "tag": "programming",
  "page": 1,
  "per_page": 20
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| query | string | No | Search URL, title, and comment |
| tag | string | No | Filter by tag name |
| page | integer | No | Page number (default: 1) |
| per_page | integer | No | Results per page (default: 50, max: 100) |

**Response:**
```json
{
  "bookmarks": [...],
  "total": 42,
  "page": 1,
  "per_page": 20,
  "has_more": true
}
```

#### POST /api/v1/bookmarks/list

List all bookmarks with cursor-based pagination. Scope: `read`

**Request:**
```json
{
  "cursor": "abc123",
  "limit": 100
}
```

**Response:**
```json
{
  "bookmarks": [...],
  "has_more": true,
  "next_cursor": "def456"
}
```

#### POST /api/v1/bookmarks/sync

Incremental sync with optional long polling. Scope: `read`

**Request:**
```json
{
  "cursor": 0,
  "limit": 50,
  "wait": true
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| cursor | integer | No | Last seen bookmark ID (0 for initial) |
| limit | integer | No | Max results (default: 50, max: 100) |
| wait | boolean | No | Enable long polling (wait up to 30s for new data) |

**Response:**
```json
{
  "bookmarks": [...],
  "cursor": 150,
  "has_more": false,
  "waited": true
}
```

### Import & Export

#### POST /api/v1/export

Export all bookmarks as JSON. Scope: `read`

**Request:** `{}`

**Response:**
```json
{
  "bookmarks": [...],
  "exported_at": "2025-01-15T10:30:00Z",
  "count": 150
}
```

#### POST /api/v1/import

Import bookmarks from JSON. Scope: `write`

**Request:**
```json
{
  "bookmarks": [
    {"url": "https://example.com", "title": "Example", "tags": ["test"]}
  ],
  "mode": "merge"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| bookmarks | array | Yes | Array of bookmark objects |
| mode | string | No | `merge` (skip duplicates) or `replace` |

**Response:**
```json
{
  "imported": 10,
  "skipped": 2,
  "errors": []
}
```

## Errors

All errors return JSON with `error` and `code` fields:

```json
{
  "error": "Human-readable message",
  "code": "ERROR_CODE"
}
```

| Code | HTTP Status | Description |
|------|-------------|-------------|
| INVALID_TOKEN | 401 | Token is invalid, expired, or missing |
| PERMISSION_DENIED | 403 | Token lacks required scope |
| VALIDATION_ERROR | 400 | Missing or invalid request data |
| NOT_FOUND | 404 | Resource not found |
| RATE_LIMITED | 429 | Too many requests |
| LIMIT_EXCEEDED | 403 | Account limit reached |

---

## Rate Limits

Default: **100 requests per 60 seconds** per token.

Headers returned:
- `X-RateLimit-Limit` - Max requests per window
- `X-RateLimit-Remaining` - Requests left
- `X-RateLimit-Reset` - Unix timestamp when window resets
- `Retry-After` - Seconds to wait (on 429 response)
