# Changelog

All notable changes to the ClipJot Android app will be documented in this file.

## [1.0.0] - 2025-02-07

### Added
- **OAuth Authentication**: Sign in with Google or GitHub
- **Invite Code Authentication**: Sign in using 8-character invite codes
- **Share Sheet Integration**: Save links from any app via Android share
- **Direct Share**: Quick share targets for faster saving
- **Bookmark Management**: View, search, and manage your bookmarks
- **Tag Support**: Add and manage tags with autocomplete
- **Comments**: Add notes to your bookmarks
- **Settings**: Configure backend URL and manage sessions
- **Material Design 3**: Modern Material You design language

### Security
- Encrypted token storage using AndroidX Security
- HTTPS-only communication
- No sensitive data logging in release builds

### Technical
- Minimum SDK: Android 10 (API 29)
- Target SDK: Android 14 (API 34)
- Built with Java 17
