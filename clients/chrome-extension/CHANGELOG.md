# Changelog

All notable changes to the ClipJot Chrome Extension will be documented in this file.

## [1.0.0] - 2025-02-07

### Added
- **OAuth Authentication**: Sign in with Google or GitHub
- **Invite Code Authentication**: Alternative sign-in method using 8-character invite codes
- **Bookmark Saving**: Save current page with title, tags, and comments
- **Quick Save Mode**: One-click save without showing the form (configurable in settings)
- **Tag Management**: Add tags with autocomplete from your existing tags
- **Context Menu**: Right-click to save links directly
- **Keyboard Shortcut**: Alt+Shift+J to open the extension popup
- **Configurable Backend**: Change the backend URL in settings (defaults to https://clipjot.net)

### Technical
- Built with Manifest V3
- Uses Chrome Identity API for OAuth flows
- DaisyUI for consistent styling
